# Clickhouse Bluesky API

The purpose of this document is to provide a list of the common bluesky APIs available through clickhouse. In [section 1](#Glossary), we will list all the APIs and provide short descriptions of them. In [section 2](#Detailed_Descriptions), we will provide or link to detailed usage as well as query outputs.

API endpoints also summarized [here](https://endpoints.bsky.app/#bluesky-app).

## 1. Glossary

| API name                     | Short Description            |
| -----------------------------| ---------------------------- |
| records_app_bsky_feed_post   | List of posts on user's feed |
| records_app_bsky_feed_repost | List of a user's reposts     |
